# Issue 05 — Teacher Learning Summary

**ชื่อเรื่อง:** ในฐานะครูพี่เลี้ยง ฉันต้องการดูสรุปหัวข้อที่ผู้เรียนติดขัด เพื่อวางแผนช่วยเหลือได้ตรงจุด

**Persona:** ครูสมชาย — Teacher Mentor

**Goal:** ดูสรุปหัวข้อที่ผู้เรียนติดขัดและผลการฝึกที่เกี่ยวข้อง

**Benefit:** ผู้สอนใช้เวลาเตรียมความช่วยเหลือได้ตรงกับปัญหาของผู้เรียนมากขึ้น

## Acceptance Criteria

- [ ] ผู้สอนที่ได้รับสิทธิ์เปิดดูสรุปหัวข้อได้
- [ ] สรุประบุหัวข้อที่มีผู้เรียนติดขัดบ่อย
- [ ] สรุปแสดงจำนวนหรือแนวโน้มผลการฝึกที่เกี่ยวข้อง
- [ ] ผู้ใช้ที่ไม่มีสิทธิ์ไม่สามารถเปิดดูข้อมูลสรุปได้
- [ ] ข้อมูลสรุปไม่เปิดเผยรายละเอียดส่วนบุคคลเกินขอบเขตที่ทีมอนุมัติ

**Labels:** `theme:learning`, `priority:medium`, `size:L`

**Milestone:** `Sprint 2 — W5–6`
