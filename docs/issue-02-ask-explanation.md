# Issue 02 — Ask for an Explanation

**ชื่อเรื่อง:** ในฐานะผู้เรียน ฉันต้องการถามเกี่ยวกับหัวข้อที่ยาก เพื่อทำความเข้าใจแนวคิดทีละขั้นตอน

**Persona:** ปันปัน — Student Learner

**Goal:** ส่งคำถามหรือเนื้อหาที่ไม่เข้าใจให้ระบบช่วยอธิบาย

**Benefit:** ลดเวลาค้นหาคำตอบจากหลายแหล่งและช่วยให้ผู้เรียนรู้จุดที่ยังไม่เข้าใจ

## Acceptance Criteria

- [ ] ผู้เรียนส่งคำถามที่ไม่ว่างได้
- [ ] ระบบแสดงคำอธิบายที่แบ่งเป็นขั้นตอน
- [ ] ระบบถามข้อมูลเพิ่มเติมเมื่อคำถามกำกวมเกินไป
- [ ] ระบบแสดงข้อความที่เข้าใจได้เมื่อผู้ช่วยภายนอกไม่พร้อมใช้งาน
- [ ] ผู้เรียนสามารถส่งคำถามต่อเนื่องจากหัวข้อเดิมได้

**Labels:** `theme:learning`, `priority:high`, `size:L`

**Milestone:** `Sprint 1 — W3–4`
