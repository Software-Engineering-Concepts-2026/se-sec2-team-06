# Issue 07 — Personal Study Schedule

**ชื่อเรื่อง:** ในฐานะผู้เรียน ฉันต้องการบันทึกตารางเรียนและกำหนดส่ง เพื่อวางแผนเวลาทบทวนได้อย่างเป็นระบบ

**Persona:** ปันปัน — Student Learner

**Backlog item:** บันทึกตารางเรียนและกำหนดส่งของตนเอง

**Goal:** เพิ่มและดูรายการเรียนหรือกำหนดส่งในมุมมองรายวันและรายสัปดาห์

**Benefit:** ผู้เรียนเห็นภาระงานล่วงหน้าและจัดเวลาถาม–ฝึก–ทบทวนได้เหมาะสมขึ้น

## Acceptance Criteria

- [ ] ผู้เรียนเพิ่มรายการโดยระบุชื่อวิชา งานหรือหัวข้อ วัน และเวลาได้
- [ ] ระบบแสดงรายการในมุมมองรายวันหรือรายสัปดาห์ตามวันและเวลา
- [ ] ผู้เรียนแก้ไขหรือลบรายการของตนเองได้
- [ ] ระบบแสดงคำเตือนเมื่อรายการใหม่ทับซ้อนกับรายการเดิม โดยไม่ลบข้อมูลเดิม
- [ ] เมื่อยังไม่มีรายการ ระบบแสดง empty state พร้อมคำแนะนำให้เพิ่มรายการแรก
