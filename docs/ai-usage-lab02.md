# AI Usage — Lab 02

## Tools used

- ChatGPT / Codex Generative AI assistant

## How AI assisted

- ช่วยตรวจ checklist และโครงสร้าง deliverables ของ Lab 2
- ช่วยเสนอรูปแบบหัวข้อสำหรับ Project Proposal และ Definition of Done
- ช่วยจัดกลุ่ม Theme, Persona, Value Proposition, MoSCoW priorities และ Risks จากข้อมูลโครงการ
- ช่วยร่างรูปแบบ User Story และ Acceptance Criteria สำหรับ Issue drafts
- ช่วยตรวจภาษา Markdown และความสอดคล้องของลิงก์ภายในชุดเอกสาร

## Human responsibility

- ทีมเป็นผู้ยืนยัน Theme `Tools for Modern Learners`, ชื่อ SynapseSync และ Persona หลัก
- ทีมเป็นผู้ตัดสินใจ MoSCoW priorities, risks, assumptions, Definition of Done และ Sprint ของ Issue
- ทีมต้องอ่าน ตรวจ และปรับเนื้อหาให้ตรงกับบริบทโครงการก่อนนำไปใช้จริง
- AI ไม่ได้สร้าง Issue, Project Board หรือ Pull Request แทนทีม
- ไม่มีการส่งรหัสผ่าน ข้อมูลบัญชี secret หรือข้อมูลส่วนบุคคลของสมาชิกเข้าไปใน prompt
