# Issue 08 — Pomodoro Focus Timer

**ชื่อเรื่อง:** ในฐานะผู้เรียน ฉันต้องการใช้ Pomodoro Timer เพื่อเพิ่มสมาธิระหว่างการเรียนและการทำแบบฝึกหัด

**Persona:** ปันปัน — Student Learner

**Backlog item:** ตัวจับเวลา Pomodoro สำหรับช่วงเรียนและพัก

**Goal:** เริ่ม หยุดชั่วคราว รีเซ็ต และสลับช่วงเรียนกับช่วงพักได้จากหน้าเรียน

**Benefit:** ผู้เรียนแบ่งเวลาเป็นช่วงสั้น ๆ และรักษาสมาธิได้โดยไม่ต้องเปิดเครื่องมืออื่นควบคู่

## Acceptance Criteria

- [ ] ระบบเริ่มตัวจับเวลาช่วงเรียนด้วยค่าตั้งต้นที่ทีมกำหนด และผู้เรียนปรับระยะเวลาได้ก่อนเริ่ม
- [ ] ผู้เรียนหยุดชั่วคราว ทำต่อ และรีเซ็ตตัวจับเวลาได้
- [ ] เมื่อตัวจับเวลาจบ ระบบแจ้งว่าช่วงเรียนสิ้นสุดและเสนอให้เริ่มช่วงพัก
- [ ] ตัวจับเวลาไม่แสดงค่าติดลบและเปลี่ยนสถานะจาก `เรียน` เป็น `พัก` อย่างชัดเจน
- [ ] ผู้เรียนยกเลิกตัวจับเวลาได้โดยไม่ทำให้คำถามหรือคำตอบที่กำลังทำหายไป

**Labels:** `theme:self`, `priority:low`, `size:M`

**Milestone:** `Sprint 2 — W5–6`
