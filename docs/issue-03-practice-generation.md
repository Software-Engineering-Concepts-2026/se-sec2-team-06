# Issue 03 — Generate Practice Questions

**ชื่อเรื่อง:** ในฐานะผู้เรียน ฉันต้องการสร้างแบบฝึกหัดตามหัวข้อ เพื่อยืนยันความเข้าใจของตนเอง

**Persona:** ปันปัน — Student Learner

**Goal:** ขอแบบฝึกหัดที่สัมพันธ์กับหัวข้อที่เพิ่งเรียน

**Benefit:** ผู้เรียนตรวจสอบความเข้าใจด้วยการลงมือทำ ไม่ใช่เพียงอ่านคำอธิบาย

## Acceptance Criteria

- [ ] ผู้เรียนเลือกหรือระบุหัวข้อสำหรับสร้างโจทย์ได้
- [ ] ระบบสร้างโจทย์ที่สัมพันธ์กับหัวข้อที่เลือก
- [ ] โจทย์มีคำตอบหรือเกณฑ์ตรวจสอบที่ชัดเจน
- [ ] ผู้เรียนส่งคำตอบและเห็นผลการตรวจได้
- [ ] ระบบแจ้งเมื่อไม่สามารถสร้างโจทย์ได้
