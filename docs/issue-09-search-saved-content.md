# Issue 09 — Search Saved Content

**ชื่อเรื่อง:** ในฐานะผู้เรียน ฉันต้องการค้นหาโน้ตและเอกสารที่บันทึกไว้ เพื่อเข้าถึงเนื้อหาที่ต้องการได้อย่างรวดเร็ว

**Persona:** ปันปัน — Student Learner

**Backlog item:** ค้นหาโน้ต เอกสาร หรือเนื้อหาที่บันทึกไว้

**Goal:** ค้นหาและกรองเนื้อหาที่ผู้เรียนบันทึกไว้ด้วยคำค้นหรือประเภทเนื้อหา

**Benefit:** ผู้เรียนกลับไปทบทวนเนื้อหาที่เกี่ยวข้องได้โดยไม่ต้องไล่เปิดรายการทั้งหมด

## Acceptance Criteria

- [ ] ผู้เรียนค้นหาด้วยคำค้นที่ไม่ว่าง และระบบค้นจากชื่อหรือเนื้อหาที่ตนเองบันทึกไว้
- [ ] ผลลัพธ์แสดงชื่อ ประเภท และวันที่บันทึกเพื่อช่วยตัดสินใจเปิดรายการ
- [ ] ผู้เรียนกรองผลลัพธ์ตามประเภทหรือหัวข้อได้
- [ ] เมื่อไม่พบผลลัพธ์ ระบบแสดงข้อความที่เข้าใจได้และคำแนะนำให้ปรับคำค้น
- [ ] ผู้เรียนเห็นเฉพาะเนื้อหาที่ตนเองมีสิทธิ์เข้าถึงเท่านั้น
