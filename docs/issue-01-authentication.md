# Issue 01 — Authentication

**ชื่อเรื่อง:** ในฐานะผู้เรียน ฉันต้องการสมัครสมาชิกและเข้าสู่ระบบ เพื่อแยกเก็บความก้าวหน้าในการเรียนของตนเอง

**Persona:** ปันปัน — Student Learner

**Goal:** สมัครสมาชิกและเข้าสู่ระบบเพื่อใช้งานพื้นที่การเรียนรู้ของตนเอง

**Benefit:** ผู้เรียนกลับมาใช้งานต่อและเห็นข้อมูลของตนเองได้อย่างเป็นสัดส่วน

## Acceptance Criteria

- [ ] ผู้ใช้กรอกข้อมูลที่จำเป็นเพื่อสมัครสมาชิกได้
- [ ] ระบบแจ้งผลสำเร็จเมื่อสมัครสมาชิกด้วยข้อมูลที่ถูกต้อง
- [ ] ผู้ใช้เข้าสู่ระบบด้วยข้อมูลที่ถูกต้องได้
- [ ] ระบบแจ้งข้อผิดพลาดเมื่อข้อมูลเข้าสู่ระบบไม่ถูกต้อง
- [ ] ผู้ใช้สามารถออกจากระบบได้

**Labels:** `theme:learning`, `priority:high`, `size:M`

**Milestone:** `Sprint 1 — W3–4`
