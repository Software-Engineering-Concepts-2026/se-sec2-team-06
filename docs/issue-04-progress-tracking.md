# Issue 04 — Track Learning Progress

**ชื่อเรื่อง:** ในฐานะผู้เรียน ฉันต้องการดูประวัติการฝึก เพื่อรู้ว่าควรทบทวนหัวข้อใดเพิ่มเติม

**Persona:** ปันปัน — Student Learner

**Goal:** ดูผลการฝึกและสถานะความเข้าใจของตนเอง

**Benefit:** ผู้เรียนวางแผนทบทวนหัวข้อที่ยังอ่อนและติดตามพัฒนาการได้

## Acceptance Criteria

- [ ] ระบบบันทึกผลการทำโจทย์หลังส่งคำตอบ
- [ ] ผู้เรียนเปิดดูประวัติการฝึกของตนเองได้
- [ ] ประวัติระบุหัวข้อ คะแนนหรือสถานะ และวันที่ได้
- [ ] ผู้เรียนเห็นหัวข้อที่ควรกลับไปทบทวน
- [ ] ผู้ใช้คนอื่นไม่สามารถดูประวัติของผู้เรียนโดยไม่มีสิทธิ์

**Labels:** `theme:learning`, `priority:medium`, `size:M`

**Milestone:** `Sprint 1 — W3–4`
