# Lab 02 — Project Board Setup

เอกสารนี้กำหนดการตั้งค่า GitHub Project Board และร่าง Issue สำหรับ Lab 2

## Project setup

- **Project name:** `Brainlink Co. — SE Concepts`
- **View:** Board
- **Columns:** `Backlog` → `Todo` → `In Progress` → `Review` → `Done`
- **Insights:** เปิดใช้งานเพื่อดู cycle time และ velocity

## Labels

สร้าง labels ตามนี้:

- `theme:learning`
- `theme:community`
- `theme:self`
- `priority:high`
- `priority:medium`
- `priority:low`
- `size:S`
- `size:M`
- `size:L`

## Milestones

- `Sprint 1 — W3–4`
- `Sprint 2 — W5–6`

## Issue drafts

ไฟล์ `issue-01` ถึง `issue-10` ในโฟลเดอร์เดียวกันเป็นร่าง Issue สำหรับสร้างเป็น GitHub Issue แต่ละไฟล์มี title, persona, goal, benefit, acceptance criteria, labels และ milestone ให้ตรวจทานก่อนเพิ่มเข้า column `Backlog`
