# SynapseSync — Project Proposal

## Theme

**Tools for Modern Learners** — ทีมเลือกพัฒนาเครื่องมือช่วยการเรียน เพราะผู้เรียนจำนวนมากต้องทบทวนเนื้อหาด้วยตนเอง แต่ไม่สามารถหาคำอธิบายหรือแบบฝึกหัดที่ตรงกับจุดที่ยังไม่เข้าใจได้ทันที SynapseSync จึงมุ่งช่วยให้ผู้เรียนตรวจสอบความเข้าใจ ฝึกซ้ำ และติดตามความก้าวหน้าได้ในที่เดียว

## Project Name

**SynapseSync** — เว็บแอปพลิเคชันช่วยเรียนที่เชื่อมคำถาม แบบฝึกหัด และความก้าวหน้าของผู้เรียนเข้าด้วยกัน

## Primary Persona

**ปันปัน นักเรียนมัธยมปลายที่เรียนรู้ด้วยตนเอง** ต้องการคำอธิบายที่ตรงกับจุดที่สงสัยและสามารถถามซ้ำได้โดยไม่รู้สึกกังวล เธอใช้สมาร์ทโฟนเป็นหลักและคาดหวังให้ระบบตอบสนองรวดเร็ว ใช้งานง่าย และช่วยให้ฝึกต่อได้ทันทีหลังเข้าใจเนื้อหา

## Value Proposition

SynapseSync ช่วยลดเวลาที่ผู้เรียนใช้ค้นหาคำอธิบายและแบบฝึกหัดจากหลายแหล่ง โดยให้ผู้เรียนถามคำถาม รับคำอธิบายทีละขั้น ฝึกโจทย์ที่เกี่ยวข้อง และบันทึกความก้าวหน้าใน flow เดียว ข้อมูลที่เกิดขึ้นยังช่วยให้ผู้สอนมองเห็นหัวข้อที่ผู้เรียนติดขัดและวางแผนช่วยเหลือได้ตรงจุดขึ้น

## MoSCoW Priorities

### Must Have

- ผู้ใช้สมัครสมาชิกและเข้าสู่ระบบได้
- ผู้เรียนส่งคำถามหรือเนื้อหาที่ไม่เข้าใจให้ผู้ช่วย AI ได้
- ระบบอธิบายคำตอบและสร้างโจทย์ฝึกที่เกี่ยวข้องได้
- ระบบบันทึกผลการฝึกและสถานะความเข้าใจของผู้เรียนได้

### Should Have

- ผู้สอนดูสรุปหัวข้อที่ผู้เรียนติดขัดและผลการฝึกได้
- ผู้เรียนดูประวัติและภาพรวมความก้าวหน้าของตนเองได้

### Could Have

- ระบบเตือนให้ผู้เรียนกลับมาทบทวนตามช่วงเวลาที่เหมาะสม
- ผู้เรียนอัปโหลดเอกสารเพื่อใช้เป็นบริบทในการสร้างแบบฝึกหัดได้

### Won't Have This Term

- การแทนที่ครูหรือตัดสินผลการเรียนอย่างเป็นทางการด้วย AI
- การเชื่อมต่อระบบ LMS ของสถาบันจริงโดยไม่มีสิทธิ์ API ที่ได้รับอนุมัติ
- การแจ้งเตือนหรือเปิดเผยข้อมูลการเรียนแก่บุคคลอื่นโดยไม่มี consent จากผู้เรียน

## Risks and Assumptions

- **คุณภาพคำตอบจาก AI:** คำอธิบายหรือโจทย์ที่สร้างอาจไม่ถูกต้อง จึงต้องแสดงว่าเป็นคำแนะนำและออกแบบให้ผู้ใช้ตรวจสอบแหล่งข้อมูลหรือรายงานปัญหาได้
- **ความเป็นส่วนตัว:** ข้อมูลคำถาม ผลการฝึก และเอกสารที่อัปโหลดอาจเป็นข้อมูลส่วนบุคคล ต้องจำกัดการเข้าถึงตามบทบาทและไม่ส่งต่อโดยไม่มี consent
- **ขอบเขต MVP:** ทีมมีเวลาและกำลังจำกัด จึงถือ flow ถาม–อธิบาย–ฝึก–บันทึกผลเป็นแกนหลัก และเลื่อน integration ภายนอกออกไปก่อน
- **สมมติฐานด้านผู้ใช้:** สมมติว่าผู้เรียนมีอุปกรณ์ที่เปิดเว็บสมัยใหม่ได้และมีอินเทอร์เน็ตเพียงพอ ต้อง validate ด้วยการทดลอง prototype กับผู้ใช้เป้าหมาย
- **บริการภายนอก:** ความพร้อมใช้งาน ราคา และ rate limit ของ LLM provider อยู่นอกการควบคุมของทีม จึงต้องจำกัดจำนวนคำขอและเตรียมข้อความเมื่อบริการไม่พร้อม
