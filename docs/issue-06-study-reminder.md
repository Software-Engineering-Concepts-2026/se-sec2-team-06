# Issue 06 — Study Reminder

**ชื่อเรื่อง:** ในฐานะผู้เรียนผู้ใหญ่ ฉันต้องการตั้งเวลาแจ้งเตือนหัวข้อที่ยังไม่ได้ทบทวน เพื่อกลับมาเรียนต่อเนื่องแม้ตารางงานไม่แน่นอน

**Persona:** พี่เอิร์ธ — Adult Learner

**Backlog item:** ตั้งการแจ้งเตือนเพื่อกลับมาทบทวนหัวข้อที่ค้าง

**Goal:** ตั้ง เปิด และปิดการแจ้งเตือนสำหรับหัวข้อที่ยังเรียนไม่จบได้ด้วยตนเอง

**Benefit:** ผู้เรียนกลับมาเรียนต่อจากจุดที่ค้างได้โดยไม่ต้องจำกำหนดเวลาหรือค้นหาหัวข้อใหม่

## Acceptance Criteria

- [ ] ผู้เรียนเลือกหัวข้อที่ยังไม่ได้ทบทวนและกำหนดวัน–เวลาแจ้งเตือนได้
- [ ] ระบบแสดงหัวข้อ วัน–เวลา และสถานะเปิดใช้งานหลังบันทึกสำเร็จ
- [ ] เมื่อถึงเวลาที่กำหนด ระบบสร้างการแจ้งเตือนที่อ้างอิงหัวข้อที่เลือก
- [ ] หากผู้เรียนปิดการแจ้งเตือน ระบบจะไม่ส่งการแจ้งเตือนตามเวลาที่เคยตั้งไว้
- [ ] ผู้เรียนกดการแจ้งเตือนแล้วกลับไปยังหัวข้อหรือจุดที่ค้างไว้ได้

**Labels:** `theme:learning`, `priority:low`, `size:M`

**Milestone:** `Sprint 2 — W5–6`
