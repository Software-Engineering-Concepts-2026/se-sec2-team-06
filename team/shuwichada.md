# Pragmatic Promise

ในรายวิชานี้ ฉันจะพยายามเริ่มทำงานและแบ่งงานออกเป็นส่วนย่อยตั้งแต่เนิ่น ๆ แทนการรอทำใกล้กำหนดส่ง นอกจากนี้จะตรวจสอบความถูกต้องของงานและสื่อสารความคืบหน้ากับทีมอย่างสม่ำเสมอ

# ทำไมอยากเรียน SE

ฉันอยากเรียน Software Engineering เพราะต้องการเข้าใจกระบวนการพัฒนาซอฟต์แวร์อย่างเป็นระบบ ไม่ใช่เพียงแค่เขียนโปรแกรมให้สามารถทำงานได้เท่านั้น ฉันสนใจการวิเคราะห์ความต้องการ การออกแบบ การทำงานร่วมกันเป็นทีม และการพัฒนาซอฟต์แวร์ให้มีคุณภาพและสามารถดูแลต่อได้ในระยะยาว ฉันคิดว่าความรู้ด้าน Software Engineering จะช่วยให้สามารถนำทักษะการเขียนโปรแกรมไปใช้ในการสร้างโปรเจกต์จริงได้อย่างมีประสิทธิภาพมากขึ้น

# Broken Window ที่เคยเจอ

ประสบการณ์หนึ่งที่เคยเจอคือการทำงานกลุ่มที่เริ่มจากสมาชิกบางคนส่งงานช้ากว่ากำหนดเล็กน้อย ซึ่งตอนแรกทุกคนคิดว่าเป็นปัญหาเล็กน้อยและปล่อยผ่านไปโดยไม่มีการตกลงวิธีแก้ไข นั่นคือ Broken Window เพราะพฤติกรรมเล็ก ๆ ที่ไม่ได้รับการแก้ไขทำให้สมาชิกคนอื่นเริ่มส่งงานช้าตามมาและการสื่อสารในทีมลดลง ผลกระทบคือเมื่อใกล้วันส่งงาน ทุกคนต้องเร่งทำงานและแก้ไขปัญหาพร้อมกัน ทำให้งานบางส่วนไม่สมบูรณ์และเกิดความเครียดภายในทีม หากมีการพูดคุยและแก้ไขตั้งแต่ครั้งแรก เช่น กำหนด deadline ย่อยและติดตามความคืบหน้าอย่างชัดเจน ก็อาจป้องกันไม่ให้ปัญหาสะสมจนกระทบคุณภาพของงานทั้งหมดได้
